VISION MEDIA — تحديث نظام الحضور والانصراف والمستخدمين والصلاحيات

تمت إضافة/تطوير التالي:

1) لوحة الأدمن / الحضور والانصراف
- صفحة مستقلة كاملة داخل الأدمن باسم: الحضور والانصراف.
- تبويبات: الحضور اليومي، سجل الحضور، الغياب والتأخير، الإجازات، التقارير، إعدادات الحضور.
- تسجيل حضور يدوي، تعديل، حذف، اعتماد، ملاحظات.
- حفظ: الموظف، رقم/معرف الموظف، التاريخ، حضور، انصراف، ساعات العمل، التأخير، الإضافي، GPS، الجهاز، طريقة التحقق، الحالة، المعتمد.
- تقارير يومية/شهرية وحسب الموظفين.
- تصدير CSV يفتح في Excel.
- طباعة تقرير كـ PDF من نافذة الطباعة.

2) الحضور من صفحة الموظف
- صفحة مستقلة: /employee أو /user
- تسجيل حضور وانصراف من الجوال.
- محاولة التحقق بالبصمة أو Face ID عبر WebAuthn عند دعم الجهاز والمتصفح.
- بديل PIN/كلمة مرور عند عدم توفر البصمة.
- حفظ GPS عند السماح بالموقع.
- منع التسجيل خارج نطاق الشركة عند ضبط الإحداثيات من الأدمن.

3) الإجازات
- طلب إجازة من صفحة الموظف.
- قبول/رفض من لوحة الأدمن.
- أنواع الإجازات: سنوية، مرضية، اضطرارية، بدون راتب.

4) الرواتب
- حساب صافي راتب تقديري بناءً على: الراتب الأساسي، الحضور، الغياب، التأخير، الإضافي، الخصومات، المكافآت.
- تسجيل الراتب كمدفوع.
- طباعة كشف راتب.
- تصدير الرواتب CSV.

5) المستخدمين والصلاحيات
- توسعة بيانات المستخدم: الاسم الثلاثي، الجوال، كود الدولة، البريد، اليوزر، الباسورد، العنوان، الوظيفة، القسم، الراتب، تاريخ بداية العمل، الصور، الملاحظات.
- عند إضافة مستخدم نوعه موظف يتم ربطه تلقائيًا بالموظفين.
- الصلاحيات تظهر تلقائيًا في صفحة المستخدم.
- المستخدم لا يرى التبويبات غير المسموح بها.

ملاحظات مهمة:
- النظام يعمل داخل المشروع Static باستخدام LocalStorage كطبقة تشغيل فورية للمعاينة والرفع على Netlify.
- بصمة الجوال في الويب تعتمد على دعم المتصفح والجهاز لـ WebAuthn؛ لذلك يوجد بديل PIN.
- لكي تكون البيانات مشتركة بين كل الأجهزة فعليًا، اربط نفس المفاتيح مع Firestore حسب الملفات الموجودة في المشروع.
- لا تضع Firestore Rules بحالة public في الإنتاج.
