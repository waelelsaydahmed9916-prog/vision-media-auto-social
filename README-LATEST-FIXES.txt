VISION MEDIA - آخر إصلاحات

تم في هذه النسخة:
1) إصلاح مشكلة تشتت الفوتر/الروابط القانونية بحيث تظهر داخل نفس الفوتر بشكل منظم وليس منفصلًا.
2) إضافة حقول إنشاء الحساب:
   - الدولة
   - المحافظة / المدينة
   - الحي
   - اختيار كود الدولة بسهم من القائمة
3) تغيير Placeholder رقم الجوال تلقائيًا حسب الدولة المختارة.
4) التحقق من رقم الجوال حسب الدولة المختارة.
5) حفظ بيانات الموقع مع حساب العميل: الدولة، المدينة، الحي، كود الدولة، رقم الجوال الكامل.

ملاحظة: تم الحفاظ على باقي المشروع بدون حذف الصفحات أو السياسات الموجودة.
