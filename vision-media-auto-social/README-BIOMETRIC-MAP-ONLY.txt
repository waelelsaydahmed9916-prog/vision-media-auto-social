تعديلات هذه النسخة:
1) تم إلغاء ربط الحضور والانصراف بالموقع الجغرافي بالكامل.
2) الحضور والانصراف في صفحة الموظف أصبح بالبصمة / Face ID / Passkey فقط.
3) أول دخول للموظف يطلب تشغيل الموقع لاستخدام النظام، ثم تأكيد البصمة مرة واحدة.
4) بعد تأكيد البصمة تختفي خانة التأكيد ولا تظهر إلا بعد موافقة الأدمن.
5) طلب تعديل البصمة يرسل إشعار وطلب موافقة للأدمن.
6) موافقة الأدمن تفتح إعادة تأكيد البصمة للمستخدم وترسل له إشعارًا.
7) تمت إضافة قسم الخرائط والمتابعة داخل الأدمن وفيه: الموظفون والمستخدمون، العملاء والزوار.
8) الخريطة للمتابعة فقط وليست شرطًا للحضور.
9) تم تعديل netlify.toml للسماح باستخدام geolocation من نفس الموقع.
ملاحظة مهمة: WebAuthn/Passkeys تعمل بشكل صحيح على HTTPS أو localhost، لذلك اختبر البصمة بعد رفع الموقع على Netlify.
