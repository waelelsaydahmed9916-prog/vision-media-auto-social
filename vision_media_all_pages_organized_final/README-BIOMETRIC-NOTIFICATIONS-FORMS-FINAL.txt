VISION MEDIA - تطوير البصمة والإشعارات واسترجاع كلمة المرور وإدارة نماذج العميل

تمت إضافة الملفات:
- enterprise-security-forms-notifications.js
- enterprise-security-forms-notifications.css
- firebase-messaging-sw.js

ما تمت إضافته:
1) نظام Passkeys/WebAuthn للبصمة و Face ID:
- لا يتم حفظ صورة البصمة.
- يتم حفظ معرف مفتاح التحقق فقط داخل biometricCredentials.
- طلبات إعادة التفعيل تظهر في لوحة الأدمن: البصمة وطلبات إعادة التفعيل.
- الأدمن يستطيع قبول/رفض الطلب وحذف البصمة القديمة وتعطيل/تفعيل البصمة.

ملاحظة مهمة:
WebAuthn لا يعمل إلا على HTTPS أو localhost. بعد رفع الموقع على Netlify سيعمل، أما فتح الملف مباشرة من الكمبيوتر file:// فلن يعمل.

2) الحضور والانصراف بالبصمة:
- صفحة الموظف تحتوي زر تفعيل البصمة وطلب إعادة التفعيل.
- أزرار الحضور والانصراف يتم تمريرها عبر التحقق بالبصمة متى كانت متوفرة.
- إذا لم يدعم الجهاز البصمة يظهر بديل PIN/كلمة المرور حسب النظام الموجود.

3) إشعارات المتصفح:
- نافذة سماح احترافية للعميل.
- حفظ token محليًا داخل notificationTokens.
- مركز إشعارات داخل الأدمن.
- تمييز المقروء وغير المقروء، حذف، إرسال إشعار يدوي، وتسجيل العملية في سجل النشاط.

ملاحظة مهمة:
إرسال Push حقيقي لكل الأجهزة عبر Firebase Cloud Messaging يحتاج Cloud Functions أو سيرفر آمن لأن مفتاح الإرسال لا يصح وضعه داخل الواجهة الأمامية. الموجود الآن يجهز Service Worker، يحفظ التوكنات، ويعرض إشعارات المتصفح عند توفر الصلاحية. لإرسال إشعارات جماعية حقيقية من الأدمن يلزم إضافة Firebase Cloud Function.

4) نسيت كلمة المرور:
- إذا Firebase Auth متاح، يستخدم sendPasswordResetEmail.
- إذا لم يكن Firebase Auth محمّلًا، يتم إنشاء طلب إعادة تعيين داخلي آمن نسبيًا مع صلاحية 10 دقائق وحد 5 محاولات ومنع إعادة الإرسال خلال دقيقة.
- لا تظهر رسالة تكشف هل البريد موجود أم لا.

5) إدارة نماذج التسجيل وطلب الخدمة:
- من الأدمن: أنظمة متقدمة > نماذج التسجيل والطلبات.
- إضافة/تعديل/حذف وترتيب الحقول.
- تحديد نوع الحقل ونطاق ظهوره: إنشاء حساب العميل، الموظف، طلب الخدمة.
- الحقول تظهر تلقائيًا في register.html و request-service.html.

6) إدارة كل أقسام صفحة العميل:
- قسم مستقل داخل الأدمن: إدارة كل أقسام العميل.
- عرض بيانات العملاء، الحسابات، الطلبات، الشات، الملفات، المدفوعات، الإشعارات، التقييمات، العناوين، سجل الدخول، الصلاحيات، النماذج، محتوى صفحة العميل، الإعدادات.

7) سجل النشاط:
- يسجل عمليات الإضافة والتعديل والحذف والإشعارات والبصمة والنماذج.
- يمكن طباعته أو تصديره CSV.

اختبار سريع بعد الرفع على Netlify:
1. افتح /admin وسجّل دخول الأدمن.
2. افتح قسم البصمة وطلبات إعادة التفعيل.
3. افتح قسم مركز الإشعارات وأرسل إشعارًا.
4. افتح قسم نماذج التسجيل والطلبات وأضف خانة جديدة لطلب الخدمة.
5. افتح صفحة طلب الخدمة وتأكد من ظهور الخانة.
6. افتح صفحة الموظف على هاتف يدعم البصمة عبر HTTPS وجرب تفعيل Passkey.

تنبيه أمان:
هذا المشروع Frontend Static. الحماية القوية النهائية للصلاحيات، WebAuthn server verification، إرسال FCM جماعي، وتشفير reset codes يجب أن تتم عبر Firebase Functions/Backend في مرحلة الإنتاج.
